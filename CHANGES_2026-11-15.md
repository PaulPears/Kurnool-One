# Kurnool One – Summary of Changes (November 15, 2026)

This document provides a comprehensive overview of all enhancements, bug fixes, UI/UX improvements, and architectural updates implemented across the **Kurnool One** mobile application (React Native / Expo), web platform (Next.js), and Firebase backend.

---

## 1. Kurnool Bazaar – Product Listings & Vendor Differentiation

- **Seller Source Identification (`sourceType`):**
  - Updated marketplace item schema with `sourceType`: `'business'` | `'professional'` | `'user'`.
  - Added visual tags on product cards across the mobile app (`OffersScreen.tsx`) and web:
    - 🏢 **Store Product** (Verified Business)
    - 💼 **Professional Listing** (Equipment / Tool / Service Package)
    - 👤 **Citizen Listing** (Pre-owned / Second-Hand Goods)
  - Resolved UI overlapping where category tags obscured product pricing.

- **Direct In-Portal Posting & Management:**
  - **Business Management (`ManageBusinessScreen.tsx`):**
    - Added dedicated **"Post Store Product to Kurnool Bazaar"** action button.
    - Added a modal to list brand-new retail products with pricing, category, warranty details, and multiple images.
    - Added **"My Bazaar Products"** dashboard allowing store owners to view active listings, mark items as **Sold**, or delete listings.
  - **Professional Management (`ManageProfessionalScreen.tsx`):**
    - Added **"Post Equipment / Package to Bazaar"** action button.
    - Added a modal allowing skilled professionals to list professional equipment, tools, or packaged work contracts.
    - Added **"My Bazaar Listings"** management section with live status and delete/sold controls.

---

## 2. Hot Deals & Festival Offers

- **Admin Visibility (`fetchAllOffersAdmin`):**
  - Added `fetchAllOffersAdmin()` in directory services to display all merchant promotions in the Admin Console without aggressive client-side expiration filters.
  - Admins can now inspect, verify, and moderate active, pending, and expired deals directly.
- **Calendar Date Picker:**
  - Created `CalendarDatePickerModal.tsx` for merchant portals.
  - Replaced manual text entry with an interactive calendar to select exact deal expiry dates (`expiresAt`).
- **UI & Alignment Fixes:**
  - Redesigned deal modal and banner cards in `OffersScreen.tsx` to eliminate overlapping between the discount pill (e.g., "FLAT 20% OFF") and the expiry countdown ("Valid Till").

---

## 3. UI/UX & Navigation Enhancements

- **Back Navigation Handling (`HomeScreen.tsx`):**
  - Implemented Android hardware back button handler (`BackHandler`).
  - Pressing the back button on the Home screen now displays an alert/toast *"Press back again to exit"*, preventing accidental app termination.
- **Auto-Scrolling Service Carousel:**
  - Added smooth auto-scroll to the "Need a Service" (Skilled Professionals) horizontal list on `HomeScreen.tsx` (scrolls every 5 seconds, pauses when user touches or drags).
- **Navigation Drawer (Hamburger Menu):**
  - Updated drawer links:
    - Corrected route from `BloodDonation` to `BloodDonors`.
    - Added direct shortcut to `HouseRent` (🏠 House Rentals / TO-LET).
    - Added direct shortcut to `Settings`.
- **Login Screen Simplification (`MobileFirebaseLogin.tsx`):**
  - Removed duplicate external web policy links.
  - Unified into a single clean legal policies row linking directly to internal `Terms` and `PrivacyPolicy` screens.

---

## 4. Subscription Integrity & Partner Referral Tracking

- **Strict Free Tier Default:**
  - Fixed an issue in `directoryService.ts` (`registerBusiness`) where listings without an explicit tier defaulted to `'featured'`.
  - Default is now strictly `'free'` across both business and professional registrations.
  - Verified free registrations write:
    - `tier: 'free'`
    - `paymentStatus: 'free'`
    - `verificationBadge: 'none'`
    - `verifiedProfessional: false`
- **Partner Referral Program Integration:**
  - Added referral partner code input to both `RegisterBusinessScreen.tsx` and `RegisterProfessionalScreen.tsx`.
  - Real-time lookup against Firestore `partners` collection displays verified partner details: `✓ Referred by: [Name] ([Area])`.
- **Perk Clean-Up:**
  - Completely removed "Social Media Boost (KMC Handles)" from all plans, pricing tables, and subscription perk definitions per explicit instruction.

---

## 5. Admin Panel – Subscription Management & Analytics

- **Manual Subscription Assignment / Upgrade Modal:**
  - Added an **"Assign / Upgrade Subscription"** control inside `website/src/app/admin/page.tsx`.
  - Admins can select any business or professional, choose plan tier (`Premium`, `Featured`, `Elite`, `Verified`), select validity duration (1, 3, 6, or 12 months), and input offline payment/UTR notes.
  - Writes upgrade history to `/subscriptions` and logs administrative action to `/admin_audit_logs`.
- **Performance Leaderboard:**
  - Added a **"Top 10 Performance Leaderboard"** inside the Leads & Analytics tab.
  - Displays top performing businesses and professionals ranked by total customer impressions, phone taps, and WhatsApp inquiries.
